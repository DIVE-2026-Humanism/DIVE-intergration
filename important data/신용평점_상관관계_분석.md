## 1. 전처리 — 측정불가(sentinel) 처리

전 컬럼 전수 스캔 결과, 측정불가 값은 **`-99999999`(9가 8개) 한 종류**이며 아래 2개 컬럼에만 존재합니다.

| 컬럼 | 측정불가 건수 | 비율 | 유효표본 |
|---|---:|---:|---:|
| 2년내 현거주지평균실거래가 | 71,650 | 71.1% | 29,166 |
| 2년내 현거주지평균전세거래가 | 66,193 | 65.7% | 34,623 |

**처리 방식**: `-99999999` → `NaN`으로 변환 후 **pairwise 제외**(해당 컬럼 계산 시에만 그 행을 빼고, 다른 컬럼 계산에는 그대로 사용).

> 0이나 평균값으로 대체하지 않은 이유: 측정불가를 0으로 두면 "거래가 0원"이라는 실제 관측값으로 오인되어, 전체의 2/3를 차지하는 가짜 0이 상관계수를 심하게 왜곡합니다.

**보존한 음수값**: `2년내 이직후 소득 증감액`의 음수 10,021건(최소 -6,333)은 sentinel이 아니라 **실제 소득 감소액**이므로 그대로 유지했습니다.

## 4. 해석

### 4-1. 연체 이력이 최대 음의 요인 (1·2·8위)

`대출연체건수`(-0.33), `연체일수`(-0.31), `카드연체건수`(-0.18)가 상위권을 점유합니다. 연체 발생 자체가 신용평점을 끌어내리는 1차 요인이며, **금액(`대출연체금액` 13위 -0.14)보다 건수·일수가 더 강하게** 작용합니다. 즉 "얼마를 밀렸나"보다 **"몇 번, 며칠 밀렸나"**가 평점에 직결됩니다.

### 4-2. 소득은 비선형 관계 — Spearman ≫ Pearson (3·4·6위)

| 컬럼 | Pearson | Spearman | 격차 |
|---|---:|---:|---:|
| 추정월소득 | +0.2804 | **+0.4062** | +0.126 |
| 추정 연소득 | +0.2664 | **+0.3858** | +0.119 |
| 2년전 추정 연소득 금액 | +0.2211 | +0.3003 | +0.079 |

Spearman이 Pearson보다 크게 높다는 것은 관계가 **단조 증가하되 직선이 아님**을 뜻합니다. 저소득 구간에서는 소득이 오를수록 평점이 가파르게 오르지만, 고소득 구간에서는 상승폭이 완만해지는 **포화(saturation) 형태**입니다.

> **모델링 시사점**: 소득 변수는 원값 대신 **로그 변환** 또는 **구간화(binning)** 후 투입해야 설명력이 올라갑니다. 실제로 Spearman 기준 정렬 시 `추정월소득`이 1위로 올라섭니다.

### 4-3. 대출은 "금액"이 아니라 "건수" (5위)

`총대출건수`(-0.24)가 `신용대출-총대출잔액`(28위, -0.04), `신용대출-총대출약정액`(29위, -0.04)보다 압도적으로 높습니다. 대출 규모보다 **다중채무 상태**가 평점에 민감하게 반영됩니다.

흥미롭게도 **주택담보대출은 양의 상관**(18·19위, +0.10)입니다. 담보대출 보유는 주택 보유·상환능력의 대리지표로 작동해, 신용대출과 정반대 방향입니다.

### 4-4. 소비 패턴의 방향성 (9·11·14·22위)

| 컬럼 | Pearson | 해석 |
|---|---:|---|
| 최근 12개월 일시불이용금액 | +0.1760 | 신용카드 일시불 = 우량 신호 |
| 최근 12개월 신용카드소비금액 | +0.1428 | 신용카드 사용 = 우량 신호 |
| 최근 12개월 체크카드소비금액 | **-0.1166** | 체크카드 편중 = 부정 신호 |
| 최근 12개월 현금서비스이용금액 | **-0.0823** | 현금서비스 = 부정 신호 |

**신용카드는 양(+), 체크카드는 음(-)** 으로 방향이 갈립니다. 신용카드 발급·한도 자체가 신용도의 결과물이므로, 체크카드 편중은 신용카드 접근성이 낮은 계층을 역으로 지시합니다. 현금서비스는 Spearman이 -0.16으로 Pearson(-0.08)의 2배라, **소액이라도 이용 여부 자체가 부정 신호**입니다.

### 4-5. 단일 변수로는 설명 불가

최대 상관계수가 **|0.33|**에 그칩니다(결정계수 R² 약 0.11). **어떤 단일 변수도 신용평점을 설명하지 못하며**, 다변량 모델이 필수입니다. 상위 변수들끼리도 강하게 얽혀 있어(`추정월소득`↔`추정 연소득`은 사실상 동일 정보, `대출연체건수`↔`연체일수` 중복) **다중공선성 제거가 선행되어야** 합니다.

**권장 변수 그룹핑**
1. **연체 축**: 대출연체건수 / 연체일수 / 카드연체건수 → 1개 대표 지표로 통합
2. **소득 축**: 추정월소득(로그) 1개만 채택 (연소득은 월소득×12로 중복)
3. **부채 축**: 총대출건수 + 추정DTI
4. **자산 축**: 총자산평가금액(주택)
5. **소비 축**: 신용카드/체크카드 비율 등 파생변수 권장

## 7. 재현 방법

```python
import pandas as pd, numpy as np

df = pd.read_csv("important data/(합성데이터)종합해커톤.csv", encoding="utf-8-sig")
df = df.replace(-99999999, np.nan)          # 측정불가 -> 결측

NOMINAL = {"성별", "직업군", "거주지 시군구 코드", "근무지 시군구 코드",
           "자가거주여부", "차량보유(국산/수입)"}
y = df["신용평점"]

rows = []
for c in df.columns:
    if c == "신용평점" or c in NOMINAL:
        continue
    m = df[c].notna() & y.notna()           # pairwise 제외
    rows.append({"컬럼": c,
                 "Pearson": df[c][m].corr(y[m]),
                 "Spearman": df[c][m].corr(y[m], method="spearman"),
                 "유효표본": int(m.sum())})

res = pd.DataFrame(rows)
print(res.reindex(res["Pearson"].abs().sort_values(ascending=False).index).head(10))
```

3. **신용평점 0점 28건** — 정상 분포에서 벗어난 이상치로, 상위 상관계수를 소폭 왜곡할 수 있습니다. 제외 후 재산출 비교 권장.
