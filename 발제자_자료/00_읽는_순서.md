## 파일 여는 방법

| 형식 | 어떻게 여나 |
|---|---|
| `.md` (텍스트) | 메모장으로도 열립니다. 표가 깨져 보이면 **VS Code**나 **Typora**, 또는 GitHub에 올려서 보면 표로 정리되어 보입니다. |
| `.html` (웹페이지) | **더블클릭하면 브라우저에서 열립니다.** 인터넷 연결이 없어도 됩니다. |
| `.csv` (표) | 엑셀로 열립니다. 한글이 깨지면 엑셀에서 `데이터 → 텍스트/CSV 가져오기 → 인코딩 UTF-8` 로 여세요. |
| `.json` (데이터) | 메모장으로 열립니다. 개발자용 형식이라 읽기 불편하면 넘기셔도 됩니다. |
| `.png` (그림) | 더블클릭. |

> 그래서 이 묶음을 따로 만들었습니다.

> 재현 명령:
> ```
> python -m hybrid.src.run --input "important data/(합성데이터)종합해커톤.csv" --outdir hybrid/outputs/ --seed 42

> 10만 행 기준 약 25초. 같은 seed로 두 번 실행하면 결과가 완전히 동일합니다.
