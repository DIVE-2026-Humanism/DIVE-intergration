### 정형 필드로는 안 나오는 진짜 요건 (자유서술)

**`earnEtcCn`** (소득기타내용)
```
청년 기준중위소득 60%(월소득 154만원) 이하, 원가구 기준중위소득 100%(월 536만원) 이하
```

**`addAplyQlfcCndCn`** (추가신청자격조건)
```
- 부모님과 별도 거주 무주택청년
 - 재산기준 : 원가구 4억7천만원 이하, 청년가구 1억22백만원 이하
```

**`ptcpPrpTrgtCn`** (참여제안대상)
```
※ 유사사업 참여 중 이거나 수혜이력이 있는 자 등
```

> 여기서 **원가구(부모) 소득·재산**과 **중복수혜 이력**은 KCB에 없는 정보다.
> 판정 주체를 `NEVER`로 명시해 자동으로 '정보부족'으로 떨어뜨려야 한다.
